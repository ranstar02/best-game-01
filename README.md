**Orbit Bloom** — a gravity-slingshot puzzle game: guide a seed of light through twelve gravity gardens, bend its flight around planets, collect every petal, and mind the thorns and black holes. Land on a planet to hop further, chain petals into combos, and earn three stars a level. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Drag to aim, release to launch. Space mid-flight fires a Nova burst. R restarts the level, P pauses, M mutes. No build step, no network: every file the game loads lives under `game/`.
